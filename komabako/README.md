# Komabako (駒箱): the piece box

Status: planned. This folder has no model yet.

The komabako is the box that holds a full set of pieces when nobody plays.

The model goes in `komabako.scad`, with its Customizer presets in
`komabako.json`. [CONTRIBUTING.md](../CONTRIBUTING.md#add-a-module) gives the
layout of a module folder.
