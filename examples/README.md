# Example models

These are demonstration exports, not slicer projects or G-code. STL files contain geometry only. 3MF files contain aligned material parts; assign them to your actual filaments in the slicer. Examples generated during the 3.0/3.1 work remain valid because subsequent optional toggles default off and the default body was preserved.

The image previews in `../images/` show actual glyph outlines composed into flat diagrams. They are not physical print photographs. Font is Noto Serif CJK JP SemiBold. Review sliced strokes, inlay assignments and bed-facing signature detail before printing.
