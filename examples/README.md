# Example models

No binary print files are released in this directory yet. Use
[models](../models/README.md) for intentionally distributable STL and 3MF
files, each with the required license sidecar. Do not commit slicer projects,
G-code, or unlicensed test exports.

The image previews in [images](../images/NOTICE.md) are original project
renders, not physical print photographs. Review sliced strokes, inlay
assignments, and bed-facing signature detail before printing.
