# Komadai (駒台): the piece stand

Status: planned. This folder has no model yet.

The komadai is the small stand next to the board. Each player puts the pieces
that they capture on their komadai, so that the opponent can see them.

The model goes in `komadai.scad`, with its Customizer presets in
`komadai.json`. [CONTRIBUTING.md](../CONTRIBUTING.md#add-a-module) gives the
layout of a module folder.
