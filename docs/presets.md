# Presets

A preset is a complete, named set of Customizer values for one piece.
OpenSCAD loads the presets for `shogi_piece.scad` from `shogi_piece.json`, so
keep the two files side by side.

| Presets | Where | How they are kept |
| --- | --- | --- |
| Shogi and Minishogi games | `shogi_piece.json`, `presets/games/` | Generated from `presets/pieces/`; see the [user guide](user-guide.md) |
| Your own designs | Saved from the Customizer into `shogi_piece.json`, or any JSON file you keep | By hand |
| Older studies and Taikyoku | `presets/misc/` | By hand |

The file formats of the piece and game sources are described in
[presets/README.md](../presets/README.md).

## Save and share

1. Open the SCAD, show Customizer, and select a preset close to what you want.
2. Change dimensions, inscriptions, font and layout. Category is informational; it never changes dimensions.
3. Inspect both faces with F5. Use Inspect signature or Inspect pawn circle when relevant.
4. Use **+** to name a new preset and save it.
5. Share the saved JSON with the matching SCAD version and the font family/version needed to reproduce it.

`shogi_piece.json` is regenerated by `python3 komascad.py build`. The build
stops, and lists what it found, if the file holds anything the piece files do
not, so nothing is lost silently. To keep a personal design clear of the
build, copy `shogi_piece.json` to a file of your own and keep your presets
there. To make a change part of the bundled games, move it into the piece
files as described in
[tuning by eye](user-guide.md#tuning-by-eye-in-openscad).

Customizer presets are flat records, not inherited profiles. Keep `fileFormatVersion` as `"1"`; numbers, booleans and numeric lists are stored as strings. Use the exact case-sensitive parameter names. Avoid partial records when distributing reproducible designs.

## Export

For a single-material STL, save the preset with Output Mode set to Model (or Blank):

```bash
openscad -o king.stl -p shogi_piece.json -P 'Shogi 01 - King (Osho)' shogi_piece.scad
```

OpenSCAD 2021.01 can give `-p` preset values priority over `-D` arguments. For STL variations, edit a copied preset rather than assuming `-D` will override it.

For color 3MF, use the exporter, not the GUI Export menu:

```bash
python3 komascad.py export shogi "King (Osho)"                      # a bundled piece
python3 komascad.py export shogi_piece.json "My piece"              # a preset you saved
python3 komascad.py export presets/misc/taikyoku.json "Fire Demon"  # any preset file
python3 komascad.py export presets/misc/taikyoku.json               # every preset in a file
```

The exporter reads saved values only, starts with SCAD defaults for omitted keys, and applies command-line text and color options last. It controls the material-part modes itself, even if the preset was saved in an Inspect view. Keep distributed presets in Model so opening them immediately shows the complete design. See the [command reference](cli.md#export).

## Linked settings and optional features

- Mirror Front Settings links twenty typography/engraving controls. Back text, color and taper remain independent; stored back settings return when disabled. Automatic size still adapts to each side's character count.
- Signature Enabled controls the optional heel mark. Also enter Signature Text. Signature settings are independent of the front/back link.
- Pawn Circle enforces a twenty-piece ring in plan view. At base 81°, shoulder and tip satisfy `2 × shoulder + tip = 378°`; Angle Mode selects the derived input. Conflicts are reported.
- Font Size and Character Spacing use 0 for automatic values. Positive values are explicit sizes/distances in mm; font size is typographic, not measured glyph height.

## Taikyoku and other games

Taikyoku presets are in `presets/misc/taikyoku.json`, together with their
[CC BY-SA 4.0 attribution](../data/ATTRIBUTION.md). For example, the Fire Demon
uses the attributed dataset's `火鬼` front and `奔火` promoted back. Its
dimensions and typography are project test defaults, not verified historical
measurements.

Confirm dimensions, glyphs, promotion relationships and font coverage before
treating any game collection as ready for play. Keep historical datasets and
their attribution separate from model defaults. Taikyoku presets and
derivative 3MF/STL files are CC BY-SA 4.0, not MIT; see
[LICENSES.md](../LICENSES.md) and [print-file licensing](print-file-licenses.md).
