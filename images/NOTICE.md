# Image provenance

The PNG and SVG files in this directory, including `rules/` and `ban/`, are
original KomaSCAD preview renders and diagrams created for this repository by
KomaSCAD contributors. They are licensed under the repository's MIT License.

They are not photographs, scans, or copied reference artwork. The rendered
glyph outlines use the selected font as normal typographic output; no font
software is embedded in an image.

When photographs of printed pieces are added, record beside each one (or in
a table here) who took it and its license. Do not add an externally sourced
image unless its source, author, license, and required attribution are
recorded beside it.
