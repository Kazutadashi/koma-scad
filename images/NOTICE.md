# Image provenance

The PNG and SVG files in this directory, including `rules/`, are original KomaSCAD preview renders and
diagrams created for this repository by KomaSCAD contributors. They are
licensed under the repository's MIT License.

They are not photographs, scans, or copied reference artwork. The rendered
glyph outlines use the selected font as normal typographic output; no font
software is embedded in an image.

Do not add an externally sourced image here unless its source, author, license,
and required attribution are recorded beside it.
